# YAYA Trust Fund Loan Management Mobile V2.2

This is an installable Progressive Web App (PWA).

## Test locally
Serve the folder through a local web server. Service workers and installation generally require HTTPS or localhost.

## GitHub Pages
Upload all files to the repository root and publish the branch with GitHub Pages. Open the published site on Android or iPhone, then use the browser's Add to Home Screen / Install option.

## Demo logins
- APP-001 / Applicant@21
- EVAL-001 / Evaluator@21
- SEC-001 / Secretary@21
- CHR-001 / Chairman@21
- ADM-001 / Admin@21

## Production security
This package is a functional prototype. Do not use it for real borrower data until credentials, authorization, application records and audit logs are moved to a secure backend. Use password hashing, server-side role checks, session expiry, account lockout, data encryption, backups and server-written audit events.
